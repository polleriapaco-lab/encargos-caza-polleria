# Encargos de Caza · La Pollería 2.0

Aplicación Android para registrar animales, preparaciones, precios, entregas
parciales, avisos por WhatsApp y totales de temporada.

La compilación automática genera el APK en la sección **Actions** de GitHub.

Las compilaciones automáticas reutilizan una firma Android estable para permitir actualizaciones sin perder los datos.
